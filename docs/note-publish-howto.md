## 貼り付けの注意

- 表は箇条書きで書いてあるので、noteの本文にそのまま貼れる

- 本文中のURL（/contract/local/... など）は自動でリンクになる
- 画像は不要。入れるなら県の数字カードのスクリーンショット1枚で足りる
