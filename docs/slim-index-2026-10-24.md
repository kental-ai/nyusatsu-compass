# 検索に出すページを絞る（2026-10-24・オーナー承認）

## 背景

2026-09のGoogleのサイト単位の評価低下（docs/postmortem-2026-09-25.md）。手動対策なし、Bingは無傷、インデックスは残ったまま
表示だけが消えた。カバレッジ（10/24時点）:

| 区分 | 件数 |
|---|---|
| 登録済み | 22,163 |
| 検出 - インデックス未登録 | **50,115** |
| 代替ページ（canonical） | 3,096 |
| クロール済み - インデックス未登録 | 73（9/10は453） |

「検出 - インデックス未登録」5万件は、Googleが見つけたがクロールする価値を認めていないページ。
「量」への評価という見立てと整合する。

## 決定（オーナー 2026-10-24）

**URLは全部残す。検索に出すページだけを13%に絞る。** 9/11の「noindexを増やさない」はこの件について撤回。
利用者からは何も消えない（リンクも本文もそのまま）。変わるのは sitemap と meta robots だけ。

## 残す基準（site/build.mjs の `SLIM`）

| 種類 | 残す条件 | 件数 |
|---|---|---|
| 地域・相場・機関・ガイド・週報・レポート等の中核 | 全部 | 約1,550 |
| 企業ページ | 国＋自治体の落札が10件以上 | 7,472 |
| 自治体の契約ページ | 予定価格か応札社数を持つ | 668 |
| 国の契約ページ | ハブのみ（個別は外す） | 149 |
| **sitemap 合計** | | **9,839**（全71,451ページの13.8%） |

外したのは 企業15,557・国の契約23,515・自治体の契約22,476 の計61,548ページ。すべてURLは生きている。

戻すときは `site/build.mjs` の `SLIM = false`。

## 副作用と対処

日次を止めた影響で、公告しかない県の `/local/<県>/` が生成されなくなり、参加資格ガイドからのリンクが33件切れていた。
県ページが実在するときだけリンクするよう修正（`localPrefPages`）。あわせて実態に合わない「（毎日更新）」の断りを1か所削除。

## 測り方

- GSC カバレッジ: 「検出 - インデックス未登録」5万件が減るか、「登録済み」が1万前後に寄るか
- 日次表示: 10月は1日10〜40。ここから離れるか
- 対照群: Bing（今回の変更の影響を受けない前提で比較する）
- 判定は次の大きなアップデートの後。3〜6か月かかる見込みで、戻らない可能性もある

## あわせて変えた運用（2026-10-24）

- 日次ルーティンを**週次**に変更（オーナー指示）。`weekly-local-awards`（月曜7:00 JST・自治体データ取得）→
  `weekly-rebuild`（月曜8:00 JST・Netlifyビルド）→ `weekly-audit`（月曜10:00 JST・監査）の順で月曜に回る
- 監査の鮮度チェックは `DAILY_PAUSED` で飛ばしていたが、週次で更新が戻るため有効に戻す
