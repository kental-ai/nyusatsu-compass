# 書き方の規約 ── 「サルでもわかる」水準で、優しく（2026-09-12）

対象: 無料メール講座（docs/stepmail.md）、有料note「実務編」、サイトの文章、SNS。
オーナー指示: 「中小企業の入札する人は難しい話を理解できない人が多い。サルでもわかるレベルで解説してあげる優しさを持って。メール講座もnoteも。」

## 読者像（書く前に思い浮かべる人）

社員10人の建設会社の専務。現場も見る。入札は年に10本くらい、夜に一人で札を決めている。
Excelは使うが「中央値」と言われると手が止まる。忙しい。読むのはスマホ。3行読んで分からなければ閉じる。

## 10のルール

1. **1文は40字まで**。句点で切る。「〜が、〜ので、〜」とつなげない
2. **1段落は3文まで**。空行を惜しまない
3. **統計の言葉を使わない**。言い換え表は下に。どうしても使うなら初出で「つまり〜」を添える
4. **数字には円の例を添える**。「率が3%下がる」→「予定価格1,000万円なら30万円下がる」
5. **比喩は生活の物で**。値札、時刻表、天気予報、体温計、車間距離。金融・統計・ITの比喩は使わない
6. **読者を責めない**。「見ていない」→「見落としがちです」。「間違い」→「よくある落とし穴」
7. **命令しない**。「〜しなければならない」→「〜を決めましょう」「〜を見ておくと安心です」
8. **結論を先に**。各回の冒頭に「今日の1行まとめ」。末尾に「今日やること（5分）」
9. **漢字とカタカナを減らす**。「算出」→「計算」、「傾向」→「クセ」、「推定」→「見当」、「トレンド」→「上がり調子・下がり調子」。業界語（札・開札・公告・落札）は残し、初出で一言説明
10. **一度に教えるのは1つ**。1通・1章に新しい考え方は1つだけ。ほかは次回に回す

## 言い換え表

| 使わない | 使う |
|---|---|
| 中央値 | 真ん中の値（安い順に並べて、ちょうど真ん中） |
| 平均 | 平均（そのまま。ただし「真ん中の値」との違いは説明しない。必要なら「だいたい」） |
| 分布 | ばらつき。「どこに集まっているか」 |
| p25／p75、四分位 | 安い方から4分の1のところ／高い方から4分の1のところ |
| p10／p90 | 安い方から10番目くらい（100件並べたら） |
| 中心レンジ（25〜75%） | 真ん中の半分が入る幅 |
| 落札率 | 落札率（予定価格の何%で落ちたか）。毎回この括弧を付けてよい |
| 予定価格 | 予定価格（役所が「この金額まで」と決めている上限） |
| 最低制限価格 | 最低制限価格（これより安い札は失格になる下限） |
| トレンド | 上がり調子／下がり調子 |
| 推定・算出 | 見当をつける／計算する |
| 傾向 | クセ |
| 交代率・入れ替わり率 | 前の年と違う会社が取った割合 |
| 現職 | 今その契約を持っている会社（「現職」と呼びます、と一度説明して以後は使う） |
| 応札社数 | 何社が札を入れたか |
| セグメント | あなたの業種×県 |
| クロス表 | 掛け合わせの表 |
| 期待値 | 「平均すると得か損か」 |

## 型（メール1通・note1章の骨組み）

```
■ 今日の1行まとめ
（結論を1文で。読者がこれだけ読んでも持ち帰れる）

■ どういうことか
（事実を1つ。実例は必ず固有名詞と円で。3段落まで）

■ なぜ大事か
（読者の損得に引き寄せる。円の例を1つ）

■ 今日やること（5分）
（サイトのページを1つ開いて、見る場所を1つ）

■ 次回
（1文）

▼ 実務編（固定ブロック）
```

## 書いたあとの点検（3つ）

- 専務が3行読んで「で、何？」と思わないか（結論が先か）
- 数字に円の例が付いているか
- 「〜しなければならない」「〜していない」が残っていないか

## 例（Before → After）

Before: 「自分の分野・方式・県の率の分布のp25〜p75を書き出し、その中のどこに置くかを先に決める」

After: 「あなたの業種の落札率（予定価格の何%で落ちたか）を、安い順に並べてみます。
真ん中の半分が、たとえば89%〜97%に入っていたとします。
まず、この幅のどこに自分の札を置くかを決めます。額を決めるのは、そのあとです。
予定価格が1,000万円なら、89%は890万円、97%は970万円。80万円の幅の中で考える、ということです。」
