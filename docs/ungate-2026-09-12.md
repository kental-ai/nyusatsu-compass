# 伏字・会員ゲートの全廃（2026-09-12）

## オーナー指示

「ページ内の数字が伏字になっている部分について、これは全部止めよう。バグっているのか、おかしなページなのか、という印象を持たれる。ウォッチ会員みたいなものもやめる。」

同日朝に「10月上旬まで触らない」と決めた直後の指示。伏字はページの見た目を壊しており、
壊れているものは直すという当初の方針の範囲でもある。

## やったこと（site/build.mjs のみ。データ・URL構造は不変）

- **3層ゲートの撤去**: `gM()`（無料会員で開く伏字・42箇所）、`gP()`（ウォッチ会員限定の桁見せ伏字）、
  `teaseYen()`、`gate.js`（cookieで復元するクライアント）、関連CSS（.g/.g-m/.g-p/.lockbox/.member-only）を削除。
  すべての数値・落札者名・前回比・中央値・推定レンジを、ページにそのまま出す
- **ウォッチ会員（有料・月9,800円・準備中）の撤去**: 契約ページの「勝てる札」ロックボックス → 参考値として素の表示に。
  企業ページの「攻略データ」ボックスは削除。月次「勝ち筋レポート」は全セグメント全文公開（sample版との差がなくなった）
- **CTAの整理**: ヘッダーの「無料会員登録して続きを見る」ボタンを削除。ページ末尾のCTAは
  「無料メール講座（全10回）を受け取る」に文言変更し、リンク先は `/alert/`（クエリなし）に固定。
  旧 `/alert/?back=...` 94,871通りは発生しなくなる（robots.txt の Disallow は旧URLの再クロール抑止のため残す）
- `/alert/` は無料メール講座＋月1レポートの登録ページとして残す。「ウォッチ対象」入力欄は削除。
  「続きが見られる」「1年間有効」等、ゲート前提の文言は welcome / thanks / policy から除去
- 類似案件検索（search.js）: 非会員20件・直近1年の制限を撤廃し、全期間100件表示に統一
- 入札機会診断（shindan.js）: CTA文言を変更

## 判断メモ

- **メール登録フォーム自体は残した**（オーナーの新規事業設計に無料講座→有料月次レポートのステップメール構想があるため）。
  ただし講座はアスメル未登録で、まだ配信されていない。フォームの約束（全10回の講座）を守るには
  アスメルのシナリオ登録（docs/stepmail.md）が前提。不要ならフォームごと外すのは容易
- docs/stepmail.md の0通目は「この端末で1年間…ご覧いただけます」とゲート前提の文言になっている。
  アスメル登録前に書き直しが必要（未着手）
- 「勝てる札」推定レンジは前回額×トレンドの機械的な参考値。伏字を外して素の数字が出るため、
  根拠と限界（中央値・最低制限価格・仕様変更は未反映）を注記に明記した
