## 検出→修正した問題（初回スキャン 41,518件 → 0件）

1. **内部リンク切れ 420→259→0件**（4クラス。いずれも「品質フィルタでページを作らない対象」への無条件リンク）
   - 機関ページ（50件未満は非生成）へのリンク: /organ/k2/（公害等調整委員会）等 → organHref/organLink ヘルパーでガード
   - groupTable内の企業リンク（2件未満は非生成）→ companyHref でガード。linkFnがnullなら文字表示
   - 県ページの市区町村リストが、市区町村ページの生成条件（own判定）と別ロジックだった
     → cityEligible を単一の判定として共有し、リンクと生成を構造的に一致させた
   - 市区町村ページ「発注の多い業務」→地域相場（30件未満は非生成）: prefCatPages集合でガード
   - 業種索引→満了レーダー（radarSlugsに無い分類）: ガード
2. **空の表 919件**: 全落札が未分類の企業で「業務分野」表がヘッダのみ → groupTableが行ゼロ時は説明文を返す
3. **description欠落**: /about/ と /alert/welcome/ を実質的な説明文に
4. **表示正規化**: 公式データの全角英数社名（Ｎｏａｈｌｏｇｙ株式会社等）をNFKCで半角化して表示
   （16,672社のtitle/h1/本文。DBキー・原データは不変。㈱→(株)等も正規化）

## 教訓
- 「ページを作らない」という品質フィルタには、必ず「リンクも張らない」が対になる。
  リンク生成は companyLink / organLink / prefCatPages / radarSlugs / cityEligible のヘルパー経由に統一した
- 検品はスポットでなく全数・毎ビルド。ゲート化したので今後の追加ページにも自動で効く
