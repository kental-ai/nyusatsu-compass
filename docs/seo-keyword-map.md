# SEO/AIOキーワードマップ（2026-08-15）

「来て欲しい検索ワード」を起点に、テンプレートごとの title / description / 見出しを設計する。
原則: (1) 主要キーワードをtitle前方に (2) 数字でCTRを取る (3) descは疑問への直答で始める
(4) AIOに直答されにくい「固有データ+道具」意図を優先 (5) 全ページOGP完備。

## テンプレート別の狙いワード

### 相場ページ /price/{slug}/（32枚・最重要）

| 狙いワード | 検索意図 | 対応 |
|-----------|---------|------|
| {業務} 落札相場 / 落札価格 | 値付けの参考 ★競合ゼロ実測済み | titleの先頭に「落札相場・落札価格」 |
| {業務} 入札 相場 / いくら | 同上（口語） | descの冒頭で「いくらで落ちる?」に直答 |
| {業務} 入札案件 / 官公庁 {業務} 委託 | 案件探し | desc内に「発注機関・公告時期」 |
| 型: `{label}の落札相場・落札価格【官公庁 実績N件】｜入札コンパス` | | |

### 企業ページ /company/{corpNo}/（16,672枚・物量）

| 狙いワード | 検索意図 | 対応 |
|-----------|---------|------|
| {会社名} 落札 / 落札実績 | 競合調査・信用確認 | titleに「落札実績・入札情報」 |
| {会社名} 入札 / 官公庁 取引 | 同上 | descに「官公庁取引」、FAQで直答 |
| 型: `{name}の落札実績・入札情報【官公庁N件】｜入札コンパス`。同名別法人372組は法人番号を併記して重複回避 | | |

### 機関ページ /organ/{code}/（43枚）

| 狙いワード | 検索意図 | 対応 |
|-----------|---------|------|
| {機関名} 入札結果 / 落札結果 | 結果の確認 ★公式PDFの上位互換 | titleの先頭に「入札結果・落札結果」 |
| {機関名} 落札 一覧 / 落札企業 | 競合調査 | descに「落札企業ランキング」 |
| 型: `{name}の入札結果・落札結果一覧【N件】｜入札コンパス` | | |

### 週報 /weekly/（毎週+1枚）

「入札 ニュース」「落札 結果 今週」等の低ボリューム+AI引用狙い。リプレイス事例が引用されやすい固有情報。

### 診断・検索（道具ページ）

「入札 案件 探し方」「官公庁 入札 始め方」等の初心者informational。AIOに直答されやすい帯だが、
「診断・検索という道具」はAIが代替できないため、descで道具であることを明示する。

## AIO/GEO（AI検索への露出）

- FAQPage/Dataset/Organization/BreadcrumbList構造化データ（実装済み）
- llms.txt をディレクトリ+想定質問つきの本格版に拡張（このコミットで実装）
- 固有データ（相場・履歴・リプレイス）はAIが直答できず「引用元」になる。定義文・直答文を各ページ冒頭に置く

## 計測

Search Consoleでテンプレート別（URLディレクトリ別）にクエリを月次確認し、
このマップの想定と実際の流入クエリのズレを見て titleを改訂する（改訂履歴はこの文書に追記）。
