# 無料と有料の境界設計（実務編・2026-09-12・レビュー待ち）

商品定義: docs/jitsumu-hen-2026-09-12.md。本書は「どこまで無料で言い、どこから有料か」を情報1つずつの粒度で決める。

## 0. 前提: サイトに出ている数字は無料（隠せない）

本番ページの実装を確認した結果（site/build.mjs）:

| 集計 | サイト表示 | 帰結 |
|---|---|---|
| 契約ごとの落札率・前回比・推定レンジ（−8%〜+4%） | あり | 無料 |
| 県ページ・方式ガイドの落札率 | あり | 無料 |
| ページごとの応札社数の平均（機関・市区町村・分野・企業） | あり | 無料 |
| 分野別・機関別の交代率、現職1回目の比率、契約ごとの連続回数 | あり（/shindan/・契約ハブ・契約ページ） | 無料 |
| 例年の落札月・発注時期パターン・満了レーダー | あり | 無料 |
| **最低制限価格**（floor_price） | **なし**。DBから読んでいるが、どのページにも描写していない | 有料の中核 |

**独占ルール**: 上の「なし」の集計は、今後もサイトに載せない。build.mjs に floor_price を描写する文・連続回数別の確率・前年比分布・日数分布を追加しない。
（載せた瞬間に有料の根拠が消える。サイトの改善で欲しくなったら、実務編の価格か構成を先に見直す）

## 1. 三層の原則

| 層 | 場所 | 出すもの | 出さないもの |
|---|---|---|---|
| L0 サイト | 全ページ | 個別の事実（この契約・この会社・この機関の数字）と、上表「あり」の集計 | 上表「なし」の集計 |
| L1 無料 | メール講座11通、note の有料ライン上、サイトのCTA | **現象の存在と大きさを示す見出し数字1つ**（全体値）。「何を見るか」 | 分解（分野別・県別・方式別・金額帯別）、閾値、判定ルール、手順、記入例、道具 |
| L2 有料 | note の有料ライン下 | 分布（p10〜p90）、クロス表、県別比較、判定基準、調整幅、手順、ワークシート、記入例、振り返り表、自県で測るレシピ | 「勝てる額」の断定 |

言い換え: **無料は「そういう数字がある」、有料は「その数字で自分の札をこう動かす」**。
見出し数字を無料で出すのは、データの実在を証明して信用を先に取るため。使い方を有料にするのは、それが読者の行動を変える部分だから。

## 4. note の構成（有料ラインの位置）

有料ラインの上（無料で読める。約1,500字）:
1. タイトル・サブタイトル・「誰向け／対象外」
2. Before → After の7行表（商品定義 1.5 節のもの。数字は見出し数字のみ）
3. 見出し数字5つ: 93%／27.7%と県差の存在／1社97.3%・11社+90.6%／±10%以内は半分／1回目36.7%・3回以上10.9%
4. 目次（7章の題名＋各章末の「やること」の題名）
5. 限界の明記（3県・当年度・公表分。勝率は保証しない）と価格
6. 「ここから有料」の直前に、第1章冒頭の2段落（率で置いて額に戻す、という考え方の説明まで。表の直前で切る）

有料ラインの下: 第1章の表から第7章のワークシート・記入例・振り返り表まで。

## 5. 漏れの点検（現行の無料資産との衝突）

| 場所 | 記述 | 判定 |
|---|---|---|
| 無料第2回 | 推定レンジ「−8%〜+4%、トレンド半分」 | サイト表示済みの計算式なので無料のまま。実務編ではこれを「たたき台」と位置づけ、率で上書きする手順を有料に置く |
| 無料第4回 | 「率89%の世界で5%動かせば失格ラインを割るか…」 | 一般論。閾値ではない。無料のまま |
| 無料第7回 | 現職1回目の比率（/shindan/ に表示） | サイト既出。無料のまま。**確率（36.7%）は見出しとして無料、配点は有料** |
| 無料第9回 | 藤沢市の実例と手順9項目 | 事実と見出しは無料。手順に当てた記入例（数値入り）は有料 |
| 月次レポート（サイト） | 狙い目契約の「現職1回目」バッジ、率の定点観測 | サイト既出。無料のまま。実務編は「バッジの裏にある確率と、それを何点と見るか」を売る |
| 入札方式ガイド（サイト） | 方式別の落札率 | 1軸のみ。分野×方式×県のクロスは有料 |

## 6. 運用ルール

- 新しい集計をサイトに足すときは、本書の表を先に見て、L2 と重ならないか確認する
- 実務編の数字は年1回（夏）に `tools/analyze_jitsumu.mjs` で再計測して差し替える。差し替え時も L1/L2 の区分は変えない
- SNS・サイトのCTA・アスメル以外の媒体で実務編を紹介するときも、使う数字は固定ブロックの2つ（27.7%・3.4倍）＋全体中央値93%まで
