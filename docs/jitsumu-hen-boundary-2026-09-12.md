# 無料と有料の境界設計（実務編・2026-09-12・v2 オーナー修正反映）

## 0. 原則（オーナー）

- **事実は無料**。公開情報の集計（落札率の分布、最低制限価格の同額率、交代確率、日数分布…）は、表ごと出してよい。サイトに載せてもよい
- **「ちゃんと考えなければならない」も無料**。問題の存在と、考えるべき問いは全部言う
- **「じゃあ、どう考えるのか」が有料**。分析手法・計算方法・判定の規則・配点・手順・道具＝ノウハウ。ここだけを売る

v1（数字の出し惜しみで線を引く案）は撤回。数字を隠すと信用が先に立たない。事実で信用を取り、方法で対価を得る。

## 1. 三層

| 層 | 中身 | 例 |
|---|---|---|
| 事実（無料） | 数字・表・実例。サイト・無料講座・noteの無料部分・SNS、どこに出してもよい | 「落札額が最低制限価格と同額の入札は27.7%。神奈川65%、群馬27%」 |
| 問い（無料） | その事実から読者が考えなければならないこと。「〜を決めなければならない」の形 | 「自県が『最低制限に寄せる県』か『分布で置く県』かを判定しなければならない」 |
| 方法（有料） | 問いにどう答えるか。手順・計算・判定基準・配点・優先順位・道具・記入例 | 「過去N件で同額率を数え、◯%以上なら寄せる県。算定式を予定価格に当てて最低制限を推定し、くじの期待値で乗るか外すかを決める」 |

無料の各回は「事実 → 問い → どう考えるかは実務編の第N章」で閉じる。

## 2. テーマ別の境界表

|---|---|---|---|

| 3 応札社数 | 応札×率の5段階表（1社97.3〜11社+90.6）。分類別・金額帯別の応札分布。1社応札9.7% | 「何社来るかを、札を作る前に想定しなければならない」 | 想定応札の推定法（同機関×同分野の過去応札の中央値を、公告の参加条件・地域要件で補正）。**応札数から率を動かす調整規則（段階と幅）**。1社応札になりそうな案件の見抜き方と、そのときの価格の置き方 |
| 4 前回額 | 前年比の分布（中央値+1.2、±10%以内49.6%、+20%超18%、−20%未満13%）。分割・混在 国6.1%／自治体17%。京都府・寝具の実例 | 「その契約が『前回額を読める半分』か『読めない半分』かを判定しなければならない」 | **判定チェックリスト**（同一年度の複数落札、工区・区域名、金額の桁の跳び、年1.8件、の条件と見る順序）。読めない場合の代替（同種契約→分野の金額帯）。トレンドの織り込み率をどう変えるか（サイトの推定レンジ「半分」を、上昇局面・下落局面・交代直後でどう調整するか） |

## 4. note の無料部分と有料ライン

無料で読める部分（約2,000字。事実は惜しまない）:
1. 誰向け／対象外
2. Before → After の7行表
3. **事実の要約表**（率の中央値、同額27.7%と県差、応札1社97／11社+90.6、±10%以内は半分、1回目36.7／3回以上10.9、公告→開札20日）。出所と限界（3県・当年度）を併記
4. **7つの問い**（第2節の「問い」列をそのまま）
5. 目次（章題＋各章の「方法」の見出し語。中身は書かない）
6. 価格・更新方針（年1回）・「勝率は保証しない」

有料ライン: 第1章「出発点の率をどう選ぶか」の規則の直前で切る。

## 5. サイトへの影響

- サイトに事実の集計ページ（例: 最低制限価格の同額率・県別、応札×率）を将来載せるのは可。信用とSEOの資産になる。10月の判断ゲートまでは触らない
- サイトに載せないのは方法（判定手順・配点・計算式・ワークシート）。サイトの文章が「どう考えるか」に踏み込みそうになったら、本書の第2節「方法」列を見て止める
- 既存のサイト文言のうち方法に近いもの: 推定レンジの式（前回額×トレンド半分、−8%〜+4%）。これは既出なので無料のまま。実務編では「この式をどう調整するか」を売る

## 6. 運用ルール

- 数字は年1回（夏）に `tools/analyze_jitsumu.mjs` で再計測。事実の更新は無料側・有料側とも自由
- 方法を変えたら（配点や閾値の見直し）、有料側だけ更新し、購入者にはnoteの追記で知らせる
- 新しい媒体で実務編を紹介するときは、事実と問いは自由、方法の中身は書かない
