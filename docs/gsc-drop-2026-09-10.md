# 検索流入の急落（2026-09-10 分析）

## 事実

日次（曜日をそろえた比較）:

| 曜日 | 8/31週 | 9/7週 | 変化 |
|---|---|---|---|
| 月 | 2,729表示 / 101クリック | 434 / 16 | **-84%** |
| 火 | 2,827 / 87 | 134 / 5 ※集計途中 | -95% |

平均掲載順位: 8.5（9/2）→ 8.7（9/3）→ 10.2（9/4）→ 12.5（9/5）→ 9.8（9/7）→ **16.0**（9/8）
下落は **9/4から開始**（9/3=2,003表示 → 9/4=974）。9/4の値は2回のエクスポートで同一＝確定値。

## 技術的な障害ではない（全て確認済み）
- robots.txt 正常（Allow: /）／全ページ HTTP 200／meta robots は index,follow
- canonical 正常（日本語URLは%エンコードで一致）
- sitemap 71,789 URL（うち市町村・地域 24,211）。shard 4〜6に地域ページを確認
- 最新のデプロイも反映済み（自治体継続契約23,208件・月次レポート公開中）

→ **Google側の評価変化**である。

## 原因の候補（可能性の高い順）

1. **大量の薄いページに対する品質評価の低下**（最有力）
   - 8/29に市町村ページを303本追加（公告履歴のみで本文が薄いページ群）、9/3にプロポーザル41本＋参加資格ガイド47本。
   - Googleの再評価は通常1〜2週間遅れで効くため、**8/29公開 → 9/4下落開始**はタイミングとして極めて整合的。
   - オーナー指摘「文字数が少なくてオリジナリティがないページがたくさんある、というサイトに見えてしまう」は、
     この現象を先に言い当てていた可能性が高い。
2. **新規ドメインの初期評価期間（ハネムーン）の終了**
   - 公開8/11から約4週間。順位が全体的に悪化する点は典型的な症状。
   - 前回（9/8）の分析で「順位が保たれている＝ハネムーンではない」と判定したが、**今回その判定は覆った**。
3. **Googleのコアアップデート**（2026年Q3に予想されていた。確証は未取得）

1と2は排他ではなく、両方が重なっている可能性が高い。

## すでに打った手（9/8〜9/9・偶然だが正しい処方箋）
- 主要テンプレの本文を大幅増補: contract/国 1,332→3,576字、contract/local 532→2,841字、company 1,704→2,632字
- 追加したのは水増しでなく実データ由来の固有コンテンツ（逐年の落札経過・落札企業の素性・分野相場の四分位・
  入札方式の実務解説・発注機関プロファイル）
- 誤った断定の全面停止（別工区の混在・分割発注の検知）
→ ただし**効果はGoogleが再クロールするまで出ない**（数週間規模）。

## 次にやること（優先順）
1. **GSCのカバレッジレポートを取得**（インデックス作成 → ページ）。
   「登録済み」の数が減っていれば deindex（ページが落とされた）、変わらず順位だけ落ちていれば評価の引き下げ。
   打ち手が全く変わるため、これが最優先の情報。
2. 慌てて構造を変えない。品質改善の効果を待つのが正着。大きな変更を重ねると原因の切り分けが不能になる。
3. ドメイン権威（被リンク）の獲得。ハネムーン明けの本質的な処方箋はこれ。
4. 薄いまま残っているテンプレ（local/市 散文561字、price/地域 396字）の増補を継続。
